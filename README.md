# knowledge-cache · 旧货鉴定

给一段争论做**过时性鉴定**，而不是判对错。目的是让说话的人发现自己**荒谬、重复、过时、像个 NPC** —— 他不是被说服的，是突然发现自己在念一份早就有人念过的台词。

## 它输出什么

```
旧货鉴定 · <这一条在赌什么>

新鲜度 xx%（陈旧率 xx%）烂
[正文自然段：他在赌什么 → 这是哪一群人 → 那场运动怎么收场 → 死因对准他这句原话]

省流：<一句能转述的话>
```

- **新鲜度 = 100% − 陈旧率**，精确到个位，不许写"约"（「约 90%」和「97%」在人心里的重量完全不同）。≥60 记「鲜」，<60 记「烂」。
- **每一方的分数写进那一方那段话里**，不另开打分表。只有一方就只有一个分数。
- **不判对错**：对错没法量；只量过时性。

## 怎么触发

贴一段争论、聊天记录、推文串、或单条观点，说"看看这是不是旧货 / 帮我鉴定一下"即可。**单条观点也合法** —— 不用凑对立方。

## 三条硬规矩（改这个包的人最容易踩）

1. **技能里不举内容层的例子** —— 不给任何现成的标签、口号、句子、比喻。一给就会被整套照搬，每份报告写得一模一样，反而像它自己在念台词。方法可以抽象；名字和句子必须每次当场找。
2. **谱系要落到"一群人 + 一场运动"**：哪一群人、它后来怎么收场（倒了／被谁取代、为什么）、这个死因跟对方当下这句话什么关系。**优先近年的、网上现成且滑稽的那一支**（要荒诞，不要庄重 —— 一提两百年前的正经学派，等于给他面子）；老运动只能兜底，且要连它滑稽的地方一起点出来；找不到就直说不确定，**不许编**。
3. **不许用退路词**：「可能」「某种程度上」「不排除」「可以理解为」一律不写。判断力优先于考据 —— 两三个特征就该知道对方要放什么屁；允许错（读者会自己修），含糊才是没用的。

本包是**单一事实源**。Hermes 侧用软链接进来，**不要拷贝**：

```bash
ln -sfn /home/riff/skills/personal/knowledge-cache ~/.hermes/skills/knowledge-cache
```
